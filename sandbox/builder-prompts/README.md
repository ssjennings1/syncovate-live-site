# Page builder prompts

Prompts for building the new Syncovate site in Taft's AI page builder. Built from `sandbox/copy-working.md` (the settled copy) and the look of the six pages in `sandbox/`.

## How to use
1. Open the Taft AI page builder on the sandbox site ("Syncovate LLC DRAFT").
2. Paste `00-master-brief.md` first. It sets the look, links, and the rule that the copy is used word for word.
3. In the same conversation, paste one page prompt at a time, in order: 01-home, 02-how-i-work, 03-workshops, 04-meet-dr-j, 05-contact, 06-saturday-seed.
4. Build the header and footer once as global sections, then reuse them.

## What to watch for
- AI builders like to rewrite copy. After each page, compare it with the page prompt. When you tell me the page is built, I can fetch it and check the wording against `copy-working.md`.
- The Saturday Seed form should be your real Taft form, not one the builder invents.
- Photos: the prompts leave "image slots" for real photos instead of stock. Add them later.
- Logo: the prompt tells the builder to use the Syncovate logo from your media library. Check which variant it picked (white on the dark header).
- The hand-built pages in `sandbox/*.html` stay as a fallback and as the reference for what "right" looks like.
